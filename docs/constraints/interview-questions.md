### Git 历史分析

```bash
# 查看最近 commit 的模式
git log --oneline --since="3 months ago" | head -50

# 查看常见 import
git log --all --pretty=format: | xargs git show | grep "import" | sort | uniq -c | sort -rn | head -20

# 查找常见的函数调用模式
git log -p --all | grep -E "(db\.|Query|Exec)" | head -30
```
